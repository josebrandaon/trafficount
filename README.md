# TraffiCount

Aplicação web para contagem manual classificada de tráfego rodoviário, desenvolvida para a Revisão do Plano Rodoviário Nacional de Cabo Verde.

- Localização GPS do posto sobre mapa (dados © OpenStreetMap, mapa © CARTO; satélite © Esri).
- Contagem por classe (motociclos, ligeiros de passageiros, ligeiros de mercadorias, pesados de passageiros, pesados de mercadorias) nos dois sentidos em simultâneo: sentido 1 = chegada, sentido 2 = saída.
- Pausas, correção −1 com o botão premido 5 s, exportação CSV, cópia de segurança JSON e pontos em shapefile (ZIP).
- Instalável no telemóvel e utilizável sem internet. Os dados ficam apenas no telemóvel.
